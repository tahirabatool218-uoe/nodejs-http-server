About This Server

This project demonstrates Node.js fundamentals by building an HTTP server without using Express.

HTTP Server

Built using Node.js http module.

Routing

Routes are handled using method and URL.

File System

Files are read and written asynchronously.

Events

Request data is handled using events.

Logging

Incoming requests are recorded in a log file.

Error Handling

File and request errors are handled properly.
